# P6 run — schema width survey, from research to gate

Project folder: [projects/p6-schema-width/](../../projects/p6-schema-width/). Programme:
[projects/PLAN.md](../../projects/PLAN.md). This log records the run and the base update that
PLAN §1 requires before a project counts as done. It covers 2026-09-24 to 2026-09-25 (commit times
below are UTC).

## Brief

P6 is a phase-1 finding-and-tool project. It asks where real knowledge-hypergraph schemas fall in
Fagin's acyclicity hierarchy and what their hypertree width is: question [01.3] of the
[register](../../kb/00-index/open-questions.md), Theme 5. It also ships a checker for relation-type
schema files (P2's `khg-relation-schema/1.0.0`, contract C1). The gate (PLAN §4): a survey table for
the Wikidata qualifier schemas and the biomedical schema; the checker reports class and width for a
given schema file and flags a constructed cyclic case.

## What was found

1. **Real KHG schemas are cyclic once roles are shared.** Every Wikidata schema is α-cyclic under
   every naming with global roles. The survey measured this under wd-roles r1; research report 02
   also covered the generic, property-local and typed namings. Relation-local roles give
   Berge-acyclic schemas with every width 1, which is a control, trivially acyclic. So the class does
   not separate the schemas; the width does. Not every KHG schema is cyclic: GO-CAM's is α-acyclic
   (report 02, finding 9).
2. **Wikidata's universal-join width is at least 3 or 4 and is not settled.** The GYO cores have 391
   to 1,446 relations. That is the size where HyperBench has exact hw for 6 of 23 graphs (300 to 999
   edges; report 01 §3.5). Every upper bound carries a validated decomposition, and every lower bound
   a stored witness.
3. **Biolink v4.4.5 is cyclic with hw = ghw = fhw = 2 exactly**, on a 5-relation core.
4. **Against HyperBench's 1,113 non-random CQs** (hw 1/2/3 = 673/432/8), the declared and
   robust-observed Wikidata schemas, with hw ≥ 4, are wider than every one of them.
5. **The number measures the universal join** on same-named roles (DESIGN §2.1), not arbitrary
   queries. Berge-acyclicity reads directly as acyclicity of the reified encoding.
6. **Declared qualifier lists overstate use.** P39 allows 104 qualifiers; the 2026-08-10 dump shows
   328 distinct qualifiers on it, of which 34 pass a noise threshold (report 02, finding 3). So declared and observed schemas are reported side by side.

## What changed in the base

- `kb/01-foundations/hypergraph-theory-results.md` (`updated: 2026-09-25`; status stays draft):
  - §5, the γ bullet: the rooted join tree must have "disjoint branches" (Brault-Baron (γ2c), after
    Duris).
  - §5 "Why it matters", rewritten. α-acyclicity is hw = 1 (GLS Theorem 4.4), the first tractable
    class, not the boundary. The boundary depends on the setting: bounded submodular width for FPT
    under the ETH (Marx), and bounded treewidth for bounded arity (Moll et al., citing Grohe). Schema
    acyclicity concerns the universal role join, not queries over the schema.
  - §6: the inequalities fhw ≤ ghw ≤ hw ≤ 3·ghw + 1 and ghw ≤ tw + 1, with a caution about the
    swapped form printed in some introductions.
  - §6: ghw ≤ k is NP-complete for k ≥ 3 (GMS 2009) and k = 2 (GLPR). GLPR's tractable cases are
    added, and "only hw is tractable to check" is replaced.
  - §6: Grohe–Marx resolved as *TALG* 11(1), article 4, 2014.

## Settled during the run, so not added to the register

- Where the HyperBench manifest lives: `datasets/hypergraph-benchmarks/` (Q1).
- Which solver answers count (Q2, Q8). A solver may preprocess to *find* a decomposition, which is
  validated on the unreduced hypergraph. Only runs without preprocessing refute.
- Reductions per measure (Q3): twin merging is never used for treewidth.
- "Uses" in wd-roles r1 rule 6 means any observed use, unthresholded (Q10).
- A demoted GHD is repaired and offered as an hw bound (Q11).

## Limits

- The base update relies on P6's reports and result files; it did not re-run the survey. Every
  number above is copied from `results/survey.md` and `survey.csv` at `7c58957`, or from the files
  cited beside it.
- Before each §1.5 correction was applied, the primary sources were read again on 2026-09-25:
  - arXiv full texts of Gottlob–Leone–Scarcello (Theorem 4.4), Grohe–Marx (§4 inequalities, abstract),
    Gottlob–Lanzinger–Pichler–Razgon (§1, Main Results 1–5, reference [34]) and Brault-Baron
    ((γ2c), Remark 7, Remark 13);
  - the abstract of Marx; the introduction of Moll–Tazari–Thurley;
  - the OpenAlex abstracts of Fagin and of Beeri–Fagin–Maier–Yannakakis.

  Every correction checked out. The one R01 had left `[unverified]` (the exact pairwise-plan
  statement) was settled from the arXiv version of Ngo–Porat–Ré–Rudra.
- The Wikidata query-log widths (Bonifati, Martens and Timm) are still quoted through HyperBench and
  stay `[unverified]` against the originals.
- **The HyperBench row's note says "selected to be cyclic", but 673 of its 1,113 queries have hw 1.**
  The selection is biased toward cyclic queries (its SPARQL and Wikidata subsets hold only cyclic
  ones; report 01 §3.2). The base says "biased toward cyclic", and the note should too.
- The review itself (independent validator, 4,000 fuzzed hypergraphs, the 4/5 severity split) is
  recorded from the project README; the review's own working files are not in the repository.
