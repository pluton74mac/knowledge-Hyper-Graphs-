## 8. Locally executed verification (2026-09-20)

Not a bibliography entry in the usual sense, but the evidence for several claims in this
section. A CPython 3.11.15 virtualenv with `hypernetx==2.4.3`, `xgi==0.10.2`,
`hypergraphx==1.8.0`, `rdflib==7.6.0`, `fastjsonschema==2.22.2`, `jsonschema==4.26.0` was used to
establish:

- `xgi.read_hif()` on a `"network-type": "directed"` file returns `xgi.core.dihypergraph.DiHypergraph`; `hypernetx.from_hif()` and `hypergraphx.readwrite.read_hif()` both return undirected hypergraphs.
- `hypergraphx.readwrite.read_hif` re-indexes node identifiers to integers, keeping the originals in per-node metadata.
- `hypernetx.hif.schema_url` == `https://raw.githubusercontent.com/pszufe/HIF_validators/main/schemas/hif_schema_v0.1.0.json`.
- The HIF schema's own `$id` (`.../pszufe/HIF_validators/main/schemas/schema.json`) returns **404**, while three other HIF schema URLs return 200.
- `rdflib` 7.6.0 has no `turtle-star` parser plugin and raises `BadSyntax` on both `<< s p o >>` and the `{| … |}` annotation syntax.
- The full I/O surface of each library, obtained by enumerating `read_*`/`write_*`/`to_*`/`from_*` symbols.

The script and its verbatim output are reproduced in
`kb/09-ecosystem/getting-started-toolchain.md`.
